# ScanRunner documentation

- [Start here](../README.md): download, installation and first assessment.
- [What's new](../RELEASE_NOTES.md): release changes and compatibility notes.
- [Assessment workflows](assessment-workflows.md): findings, exports, optional tools and local operations.
- In the terminal: `scanrunner guide`, `scanrunner --whats-new` or `scanrunner help COMMAND`.

The files under [source archive](https://github.com/Madhav-Sai/scanrunner/tree/main/docs/archive) describe older releases. Use the current
README and command help for supported commands.

For contributors, `tests/`, `scripts/`, `lab/` and `.github/workflows/` contain
regression tests, release tooling, owned lab environments and CI. They are not
included in the application download.
